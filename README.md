# atlas-fundamentos

Repositorio de prácticas de Academia Atlas. Ejercicios de aprendizaje de Python, Git y GitHub.

## Contenido

Ejercicios y proyectos del Nivel 1 — Fundamentos de Programación en Python.
- `saludos.py`- Acceso a un elemento por su índice y recorrido de la lista con un for.
- `condicionales.py`- Clasificación de valores con if/elif/else y operadores lógicos
- `bucles.py`- Aprendizaje de bucles for. 
- `funciones.py`- definición de funciones con parámetros y diferencia entre print y return.

## Tecnologías

- Python 3.9 o superior


## Cómo ejecutarlo

1. Clonar el repositorio en tu máquina local.
2. Abrir la terminal y navegar hasta el directorio del proyecto.
3. Ejecutar el archivo deseado con el comando `python nombre_del_archivo.py`.
4. Ver los resultados en la terminal.
